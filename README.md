# Салон красоты — Лабораторная работа №2

Проект разделен на две части в соответствии со структурой курса:
- **`my-api/`** — серверный API (Express + PostgreSQL / SQLite) и панель тестирования записей (Vite).
- **`my-app/`** — клиентское веб-приложение салона красоты (каталог, фильтры, корзина, личный кабинет, админка, темная тема).

## Запуск проекта

### 1. Сервер (Бэкенд)
```bash
cd my-api/backend
npm start
```
Сервер запустится на `http://localhost:3100`.

### 2. Клиентское приложение (Фронтенд)
```bash
cd my-app
npm run dev
```
Сайт откроется на `http://localhost:5173`.

### 3. Панель управления записями API (Тестовый клиент)
```bash
cd my-api
npm run dev
```
Интерфейс откроется на `http://localhost:5174`.
